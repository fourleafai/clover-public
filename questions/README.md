# questions/

Open question bank dataset — 500+ interview questions across 24 roles with 5-dimension scoring rubric anchors. **Coming soon.**

Vanilla JSON, MIT-licensed, no client lock-in. The MCP server consumes this dataset; you can also depend on it directly from any code or tool.

When shipped this folder will publish as the `four-leaf-questions` npm package (or `@four-leaf/questions` if the scope is claimed) with JSON + YAML formats and a JSON schema.

See the [top-level README](../README.md) for the bigger picture.
